# Shiva Gallery — Women's Clothing Store

Full-stack e-commerce app for a women's clothing store, with a Django backend and a React frontend.

**[English](#english) | [فارسی](#فارسی)**

> A static front-end mockup of the same "Shiva Gallery" brand also exists at [shopping-website](https://github.com/alirezaalamshah/shopping-website).

---

## English

### About

An online store for women's clothing: product catalog, shop management via Django admin, and a React storefront.

### Tech Stack

**Backend**
- Django (`shiva_gallery` project, `shop` app)
- SQLite

**Frontend**
- React (`ShivaGallery`)

### Getting Started

```bash
# Backend
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

# Frontend
cd frontend/ShivaGallery
npm install
npm run dev
```
